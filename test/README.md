# Unit Tests

This directory is intended for unit tests of platform-independent logic in the `xDuinoRails_MotorControl_bEMF` library.

## Current Status
As of the current version, the test infrastructure is being established.

## Planned Tests
- Circular buffer management
- Math utility functions
- HAL interface logic (mocked)

## Running Tests
Tests will be executed using PlatformIO's test engine:
```bash
pio test
```
